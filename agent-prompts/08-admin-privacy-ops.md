# 阶段 8：管理后台、数据权利与运维闭环

前置：阶段7通过。阅读 `docs/04-api.md` 第10节、`docs/08-security-privacy.md`、`docs/10-cost-operations.md`。

## 目标

实现轻量管理后台、站内通知、匿名指标、用户导出/删除/注销、管理员限时支持访问、费用与能力监控。

## 必须交付

- 邀请码、用户状态、来源、采集任务、死信重试、能力矩阵、模型费用和预算。
- 站内通知；不接邮件/微信岗位提醒。
- 匿名产品事件，不含正文、联系方式、完整 URL 参数。
- 用户完整 ZIP 数据导出：JSON + 自有文件，重新认证、异步、短时下载。
- 聊天90天保留和单独删除。
- 注销7天恢复期，到期删除 DB、pgvector、OSS、派生版本；备份到期说明。
- 用户发起、指定简历/原因/期限的管理员支持授权；默认管理员无正文。
- 50/80/90/100%预算行为、能力独立禁用和运行手册。

## 验收

- 管理员越权和授权过期测试。
- 删除任务某一子项失败时整体不能标成功，并可安全重试。
- 数据导出不含其他用户、系统密钥、内部提示词或风控规则。
- 日志敏感扫描、OSS ACL/签名 URL、会话安全测试。
- 备份与恢复先在本地/测试环境演练并保留证据，不声称云端已验证。
