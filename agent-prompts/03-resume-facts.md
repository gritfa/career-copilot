# 阶段 3：简历上传、解析与事实库

前置：阶段2已通过。阅读 `docs/01-prd.md`、`docs/03-data-model.md`、`docs/05-ui-ux.md`、`docs/08-security-privacy.md`。

## 目标

实现文本型 PDF/DOCX 的安全上传、异步解析、候选事实、证据定位、用户确认和事实版本。

## 必须交付

- Storage Adapter（本地开发实现；OSS 接口留到后续真实集成）。
- 文件白名单、magic bytes、大小/页数/压缩/超时限制和恶意文件扫描接口。
- Celery 幂等解析任务和安全失败状态。
- 原始文件、提取文本、解析版本、候选事实分层存储。
- 候选事实接受、编辑后接受、拒绝；确认后才生成 `profile_fact`。
- 事实 provenance、证据定位、替代/废止版本。
- 前端上传、进度、错误和逐类事实确认页面。
- 删除单份简历的依赖预检查和异步清理骨架。

## 边界

- 不支持 OCR、图片或旧 `.doc`。
- 不使用网络真实个人简历测试。
- 如暂未接真实模型，使用确定性解析 + 合成结构化 Adapter；能力状态标记真实情况。
- 不将姓名、电话、照片加入后续向量文本字段。

## 验证

覆盖合法/伪装/超大/损坏/复杂文件、解析超时、任务重试、跨用户越权、未确认事实不能被引用、日志正文扫描。
